## Devlog

1. When writing part 2 fixing the if statement was where I had trouble the most. Firstly, I knew I had to use parentheses surrounding the code after an if statement but used a ";" to close it. This made my code not run correctly since my spell's wouldn't execute correctly. It was only after looking into the if syntax again did I see that it should just be if (code){} to correctly execute all of the code since ";" closes the if statement before running the full block of code.
